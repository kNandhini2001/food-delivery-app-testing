# Food Delivery Application Testing

Practice QA portfolio for a fictional food delivery application. Contains 50 designed test cases, requirements, traceability and illustrative defects. No application was executed; all cases are Not Run. Not affiliated with Licious.

## Files
- Test_Plan.md: scope and rules
- Test_Cases.csv: test design
- RTM.csv: requirement mapping
- Sample_Bug_Reports.md: hypothetical defects
- Test_Execution.csv and Test_Summary.md: execution templates
